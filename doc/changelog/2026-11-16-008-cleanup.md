# CHG-20261116-008：过期数据清理

- 日期：2026-11-16（Asia/Shanghai）
- 变更类型：新增
- 文档状态：已更新
- 功能状态：进行中。过期清理已接入且默认关闭；上传未做，阶段 08 整体未完成

## 背景与原因

登录计数和超过绝对寿命的会话会持续堆积。需要一个默认不运行的清理任务，避免多副本同时删除，也不误删仍要识别重放的刷新记录。

## 涉及模块与文件

- `project/src/modules/maintenance/cleanup.service.ts`
- `project/src/modules/maintenance/cleanup.schedule.ts`
- `project/src/modules/maintenance/maintenance.module.ts`
- `project/src/config/env.validation.ts`
- `project/package.json`

## 具体变更

安装 `@nestjs/schedule@12.0.2`。新增 `SCHEDULE_ENABLED`，缺省 false。关闭时不注册定时器。打开后每小时整点（UTC）执行一次。每次最多删除 500 条已到期登录计数，以及 500 条已超过 `SESSION_MAX_TTL_SECONDS` 的会话。会话删除级联删除刷新记录。数据库失败只写 JSON 日志。

## 兼容性影响

缺省配置下启动行为不变。没有新增 HTTP 接口，也没有改表。

## 数据库影响

无 Schema 变更。任务运行时删除已到期的 `auth_attempt_buckets` 行，以及已超过绝对寿命的 `sys_user_session` 行。

## 验证方式与结果

2026-11-16 直接调用清理，没有打开定时器。临时数据里，已到期的登录计数和已超过绝对寿命的会话被删掉，后者的刷新记录也没有留下。未到期的计数、会话和刷新记录都还在。再调用一次，这三项数量不变。临时数据已删除，剩余 0。同一次调用还删除了库里原本已经到期的登录计数。
