# CHG-20261116-005：关键写操作审计

- 日期：2026-11-16（Asia/Shanghai）
- 变更类型：新增
- 文档状态：已更新
- 功能状态：进行中。启用停用、软删除、角色分配、改密和退出已写审计；查询接口未做，阶段 08 整体未完成

## 背景与原因

这些操作会改变用户能否登录或能做什么。成功记录需要和业务写在同一个事务里，失败时不能留下一条假的成功审计。

## 具体变更

新增 `audit_logs`。字段是操作者、动作、对象类型、对象 id 和 `requestId`。外键指向 `users`，删除限制为 RESTRICT。

启用、停用、软删除、角色替换、修改密码、当前退出和全部退出，在原事务末尾写入审计。原密码错误不写成功审计。没有查询、修改或删除审计的接口。

## 兼容性影响

没有新的 HTTP 路由。物理删除仍被审计引用的用户会因外键失败。现有接口的成功响应不变。

## 数据库影响

新增迁移 `20261116140000_add_audit_log`，只建表和一条外键。已应用。没有 reset，没有改写旧迁移。

Darwin arm64。工作目录 `project/`。`tsc --noEmit --incremental false -p tsconfig.build.json` 和改动文件的 ESLint、Prettier 退出码 0。迁移 `20261116140000_add_audit_log` 已由 `prisma migrate deploy` 应用。
