# CHG-20261031-006：增加用户会话表

- 日期：2026-10-31（Asia/Shanghai）
- 变更类型：新增
- 文档状态：已更新
- 功能状态：Schema 已实现；认证模块与迁移未实现、未验证

## 背景与原因

用户授权按 JWT 与 Refresh Token 方案设计会话表，只改表模型，不改业务模块。

## 涉及模块与文件

- `project/prisma/schema.prisma`
- [阶段 05](../05-authentication/implementation.md)、路线图与导航

## 具体变更

新增 `UserSession`，映射 `sys_user_session`。Int 自增 `id`，`userId` 关联 User 且删除用户时 Restrict。`refreshTokenHash` 唯一，VarChar(255)。`expiresAt` 必填，`revokedAt` 可空。列名使用 `user_id`、`refresh_token_hash`、`expires_at`、`revoked_at`、`created_at`、`updated_at`。User 仅增加 `sessions` 关联。未写登录、刷新或退出代码。

## 兼容性影响

没有 HTTP 接口变化。用户模块代码未改。

## 数据库影响

没有创建或应用迁移。
