# CHG-20261115-002：补用户体系安全验收

- 日期：2026-11-15（Asia/Shanghai）
- 变更类型：核对
- 文档状态：已更新
- 功能状态：进行中。过期令牌、错误算法、数据库故障和两名管理员互删已本地 HTTP 验收；阶段 05、06 整体未完成

## 背景与原因

用户主链已经走通。过期 Access、错误签名算法、数据库故障不放行，以及两名管理员同时互删，还没有同一次请求证据。

## 涉及模块与文件

- [阶段 05](../05-authentication/implementation.md)
- [阶段 06](../06-authorization/implementation.md)

验收脚本只在本次执行，未保留。没有修改应用代码。

## 具体变更

没有接口或数据变化。Guard 对过期 HS256 和 HS512 都返回 401。会话表不可用时返回 503，不放行。两名管理员同时清空对方角色时，一个成功，一个返回 409，结束后仍有一名有效管理员。

## 兼容性影响

没有行为变化。

## 数据库影响

无 Schema 变更。没有新迁移。验收把 `sys_user_session` 改名一次并在该请求后改回。已有管理员的 admin 关联在并发测试期间卸下，结束后加回。临时用户已物理删除。结束后有效管理员仍为 1 名。

## 验证方式与结果

Darwin arm64、Node 24.18.0、pnpm 11.13.1。工作目录 `project/`。验收脚本退出码 0。输出不含 token 或密码。

- 有效 Access 返回 200，`code` 为 `OK`。
- 过期令牌返回 401，`code` 为 `UNAUTHENTICATED`。
- HS512 令牌返回 401，`code` 为 `UNAUTHENTICATED`。
- 会话表不可用时返回 503，`code` 为 `SERVICE_UNAVAILABLE`。表名改回后同一 Access 返回 200。
- 互删角色一个 200、一个 409。当时有效管理员为 1 名。
- 已有管理员关联已加回，有效管理员仍为 1 名。临时数据剩余 0。

未覆盖错误 issuer、audience、刷新或登录计数中的数据库故障、批量删除和密码重置。
