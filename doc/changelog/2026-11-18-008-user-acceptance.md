## 验证方式与结果

环境：win32 x64、Node 24.22.2，目录 `project/`。应用监听 `http://127.0.0.1:3015/api/v1`。

- 创建时带密码返回 400，且不回显密码。正常创建返回 201，邮箱小写，用户名保留大小写，响应没有 `password`。
- 未设密登录 401。设密 200，重复设密 409。
- 搜索总数 1。`page=0`、非法 ID、未知 `sort` 为 400。不存在的 ID 为 404。
- 昵称 null 清空成功。邮箱 null 返回 400。空资料对象返回 404。
- 重复邮箱 409。停用和启用分别得到状态 0 和 1。
- 软删除后详情和资料更新为 404，搜索总数为 0，原身份重建为 409。删除自己为 403。
