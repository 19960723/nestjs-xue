# CHG-20261116-004：一行 JSON 日志

- 日期：2026-11-16（Asia/Shanghai）
- 变更类型：修改
- 文档状态：已更新
- 功能状态：进行中。应用日志和访问日志已是一行 JSON；审计未做，阶段 08 整体未完成

## 背景与原因

安全响应头和请求体限制已经接上。访问日志还是普通文本，启动日志和错误堆栈也没有同一出口。

## 涉及模块与文件

- `project/src/common/logging/json-logger.ts`
- `project/src/common/middleware/request-context.middleware.ts`
- `project/src/common/request-context.service.ts`
- `project/src/common/filters/all-exceptions.filter.ts`
- `project/src/app.module.ts`

## 具体变更

新增 `JsonLogger` 和 `writeJsonLog`。Nest 日志与访问日志都写一行 JSON 到标准输出。字段包含 time、level、context、requestId、event。访问日志另有 duration、status、method 和最多 200 字符的 path。path 不含查询串，不写请求头和正文。非字符串日志改成固定文案。堆栈中的 mysql:// 与 redis:// 会抹掉。

## 兼容性影响

日志格式从文本变成 JSON。HTTP 响应不变。

## 数据库影响

无 Schema 变更。没有新迁移。

## 验证方式与结果

Darwin arm64。工作目录 `project/`。`tsc --noEmit --incremental false -p tsconfig.build.json` 和改动文件的 ESLint、Prettier 退出码 0。

重启后 `GET /health/live` 返回 200，响应 `requestId` 为 `json-log-check-01`。标准输出里对应一行可解析的 JSON：`event` 为 `http.completed`，`status` 为 200，`method` 为 `GET`，`path` 为 `/api/v1/health/live`，`duration` 是数字，没有 `stack`。阶段 08 不标为已验证。
