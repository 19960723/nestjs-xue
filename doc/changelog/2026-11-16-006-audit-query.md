# CHG-20261116-006：审计只读查询

- 日期：2026-11-16（Asia/Shanghai）
- 变更类型：新增
- 文档状态：已更新
- 功能状态：进行中。审计列表已提供；上传和定时任务未做，阶段 08 整体未完成

## 背景与原因

审计已经在关键写操作里落库。需要一个只读入口查看这些记录，同时不能改写或删除。

## 涉及模块与文件

- `project/src/modules/audit/audit.controller.ts`
- `project/src/modules/audit/audit.service.ts`
- `project/src/modules/audit/dto/query-audit.dto.ts`
- `project/scripts/seed-permissions.mjs`

## 具体变更

新增 `GET /audit-logs`。分页字段是 `list`、`total`、`page`、`pageSize`。可按动作、操作者用户 ID 和起止时间筛选。需要 Access 和 `audit:read`。响应字段与审计表一致。没有修改或删除接口。

权限目录增加 `audit:read`。再次执行种子会把它补进系统管理员角色。

## 兼容性影响

新增公开路径上的受权接口。未持有 `audit:read` 的登录用户得到 403。

## 数据库影响

无 Schema 变更。没有新迁移。权限行由种子写入。

## 验证方式与结果

2026-11-16 用临时账号访问 `GET /audit-logs`。未登录 401 `UNAUTHENTICATED`。已登录但没有 `audit:read` 时 403 `FORBIDDEN`。持有该权限时 200，列表包含刚写入的 `auth.logout`。按动作和操作者筛选后 `total` 为 1；换成 `users.delete` 后 `total` 为 0。开始时间晚于结束时间返回 400 `VALIDATION_ERROR`。响应里没有密码字段。临时用户、角色和审计已删除，剩余 0。

权限种子已再次执行：权限 10 条，系统管理员角色关联 10 条，成员角色关联 0 条。没有新建管理员，也没有移除已有的用户角色关联。
